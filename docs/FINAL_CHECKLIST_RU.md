### Результаты краш-теста и сквозного аудита (02.11.2026)

Повторный запуск в текущей ограниченной среде не является полным прогоном: `npm test` останавливается при `initdb` из-за запрета SysV shared memory (`shmget: Operation not permitted`); сетевой OIDC-мок и проверка свободного порта для Admin-сборки блокируются запретом loopback bind. Прямой запуск без этих подсистем дал 12 успешных тестов, два PostgreSQL-теста пропущены, OIDC fixture заблокирован `EPERM`. Полный предыдущий прогон 29/29 на одноразовой synthetic PostgreSQL-БД остаётся последним полным доказательством; перед сдачей повторить его в среде, где разрешены локальные сокеты.

### 1. Зафиксировать совместимость стенда

- [x] Сверено: ТЗ буквально просит готовые образы Encvoy на базе версии 1.2; пользователь выбрал использовать последнюю версию. В проекте реально проверены vendor-образы 3.6.19, закреплённые digest. Публичная документация Trusted.ID сейчас размечена как v3.4, а публичная страница GitLab содержит тег исходников v3.2.53; закрытый registry не отдаёт список тегов без авторизации. Поэтому в отчёте писать «последняя проверенная в проекте версия образов — 3.6.19», не утверждать, что это доказанно самый последний опубликованный релиз. Образы не привязаны к GitHub snapshot 1.2.0; трактовка для сдачи: используем выбранную пользователем последнюю проверенную сборку и явно указываем отличие от буквальной версии ТЗ.
